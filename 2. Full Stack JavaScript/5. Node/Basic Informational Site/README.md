# Basic Informational Site

## About The Project

[The Oding Project](https://www.theodinproject.com): Basic Informational Site.
Exercise as part of the Full-stack JavaScript curriculum on Node.

## Project Overview

Basic HTTP server that routes traffic based on URL. It is built with NodeJS and Typescript.
The goal of this exercise is to apply learnings from the NodeJS introduction.

The project offers the below functionalities:

- Node HTTP server.

## Instructions

The full set of instructions can be found at [The Odin Project ](https://www.theodinproject.com/lessons/nodejs-basic-informational-site).

- Create 4x basic HTML pages:
  -- index.html
  -- about.html
  -- contact-me.html
  -- 404.html
- Create the node server and add the code needed to serve the right page according to the url.
